# 词间 v0.27.0

这一版把原来以 Watch7 480 圆屏为基准的界面升级为圆屏、方屏和不同尺寸 Wear OS 手表共用的自适应布局。

- 圆屏继续使用原来的弧边安全区，Watch7 44mm 的位置和比例保持不变。
- 方屏会把圆屏预留的左右空间交给按钮、答案卡和文字，不再把圆屏画面原样塞在方框中央。
- 225dp 以上启用大屏档，横向点击区域展开 16%；较小方屏展开 10%。
- 长方形屏幕按短边等比缩放并在长轴居中，字体、图片和卡片不会被拉伸。
- 外圈进度在圆屏上保持弧线，在方屏上变成圆角方形边框和顶部进度段。
- 触摸表圈在圆屏使用径向环带，在方屏使用四条物理边缘；系统旋转表冠、DPAD 和直接触摸继续通用。
- 没有旋转表冠的手表也能通过直接触摸、边缘手势和滚动完成全部学习流程。
- README 新增方屏真实 View 预览，并将发布包改名为 `WordHalo-WearOS-v0.27.apk`。

自动化新增三类档案：480 × 480 方屏、384 × 384 小圆屏和 400 × 480 长方屏。测试检查所有直接场景控件都在屏幕内、按钮文字不裁切、静默学习适配、225dp 断点展开以及方屏边缘表圈输入。

可直接覆盖安装。包名、签名、数据库结构和单词 ID 不变，学习进度、收藏、设置及未完成学习组均保留。版本号为 12。

验证：42 项 Android API 36 原生运行测试、63,834 条学习逻辑断言全部通过。APK 使用与此前版本相同的签名证书，并通过 zipalign 与 APK Signature Scheme v3 校验。

Galaxy Watch7 44mm 是实机验证设备；方屏、小圆屏和长方屏目前属于 API 36 原生渲染与交互验证，不冒充对应型号的真表测试。
