# 词间 v0.26.0

这一版把“上课空几秒背一张”的场景做成独立的静默速记流，并让返回手势真正跟随手指。

- 首页新增“静默 5”入口，每次安排 5 张当前词书里的到期词或新词。
- 单词先保持遮挡词义；点“看词义”或转动虚拟表圈即可揭晓，再选择“忘了 / 记得”。
- 判断后立即进入下一张，忘词仍按原遗忘曲线进入错词、稍后重现，首次结果不会被重试覆盖。
- 静默流程不自动发声、不自动查询音标、不请求网络；主动轻触单词仍可进入原有读音页。
- 当前卡、是否揭晓、表圈焦点和答题进度写入原有会话，息屏、切后台和 Activity 重建后可以继续。
- 外圈进度按首次处理的不同单词计算，错词加入重试队列时不会让进度倒退。
- 返回改为从左侧 20% 边缘起手，页面随手指平移、淡出并轻微收缩；距离不足会平滑回弹，纵向滚动会取消返回候选。
- 首页重新排成“完整学习 / 静默 5 / 错词 / 更多”四个明确入口，并更新真实 480 × 480 View 预览。

可直接覆盖安装。包名、签名、数据库结构和单词 ID 不变，学习进度、收藏、设置及未完成学习组均保留。版本号为 11。

验证：39 项 Android API 36 原生运行测试、63,834 条学习逻辑断言全部通过。静默模式的零自动网络、会话恢复、大字体布局、表圈操作，以及左缘返回的跟手、回弹和防误触均有自动化覆盖。APK 使用与此前版本相同的签名证书，并通过 zipalign 与 APK Signature Scheme v3 校验。

Watch7 用户已实测的既有安装、学习、触感、虚拟表圈、联网和后台退出范围继续保留；0.26 的静默速记与左缘跟手返回需要覆盖安装后按实机继续反馈。
