# 词间 v0.25.0

这一版重做手表端动效架构，让页面、表圈与答题反馈使用统一、克制且连续的过渡。

- 页面切换采用双场景合成，旧页面平稳退场，新页面按前进或返回方向进入。
- 翻词、翻卡、统计翻页和答题揭晓复用同一动效协调器，不再让每个控件各自动画。
- 连续旋转虚拟表圈时，焦点框从当前位置直接追随新目标，并根据移动距离调整时长。
- 答题结果改为平滑缩放淡入；错误反馈保留短促横向节奏，但去掉突兀回弹。
- 按钮加入轻微按压和释放反馈，外圈学习进度平滑过渡。
- 页面级动画以两个硬件合成层运行，结束后立即移除旧层；没有循环动画或后台动画。
- “过渡动画”开关和系统动画策略会完整关闭新动效；退到后台会取消动画并释放临时层。
- 保留 v0.24 的本机英美发音、后台断网、六本独立词书、遗忘曲线、图片联想与分层震动。

可直接覆盖安装，包名、签名、数据库和单词 ID 不变，学习进度、收藏、设置及当前学习组均保留。版本号为 10。

验证：37 项 Android API 36 原生运行测试、63,830 条学习逻辑断言全部通过。APK 使用与此前版本相同的签名证书，并通过 zipalign 与 APK Signature Scheme v3 校验。

Watch7 用户已实测的既有安装、学习、触感、虚拟表圈、联网和后台退出范围继续保留；0.25 新动效的最终帧率和手腕观感需要覆盖安装后按实机继续反馈。
