# 词间 v0.22.0

本版加入 6 本彼此独立的四六级词书。先选四级或六级，再选择星火、新东方或闪过；每次只启用一本，词数、来源顺序、已学进度和复习安排均按当前词书显示。切换词书从下一组生效，重合单词沿用个人记忆记录。

- 四级：星火 2261 词、新东方 4447 词、闪过 5821 词。
- 六级：星火 2999 词、新东方 2744 词、闪过 5325 词。
- 安装包共存储 7981 个去重词条，并以独立顺序表保留每本书的成员和顺序。
- 覆盖安装保留进度、错词、收藏和设置；无效的旧版未完成组会安全丢弃，不影响个人进度。
- 修复背词时自动查询地区音标导致 Wi-Fi 被频繁唤醒的问题；现在只有点击英式/美式播放才联网，划掉后台任务会断开请求、释放播放器并销毁网络线程池。
- 继续基于 Wear OS 6 / Galaxy Watch7 44mm 优化，包名及签名不变，可直接覆盖安装。

百词斩“六级核心（过考版）”2551 词未包含在本版中，因为尚未取得可核验的完整清单和顺序。详细版本、数据来源和许可见 `VOCABULARY-SOURCES.md`。

验证：35 项 Android API 36 原生运行测试、63,830 条学习逻辑断言全部通过。
