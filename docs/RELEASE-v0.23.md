# 词间 v0.23.0

这一版集中重做图片联想和表圈焦点质感。

- 新增 72 张六级高频抽象词专属插画，每个词都有独立图片和中文“图中元素 → 词义”提示。
- 法律、医疗、经济、协作、学术五类原先重复最严重的通用照片已被专属图替换。
- 旧图库映射经过筛选，从 268 个关联精简为 144 个可靠关联；同一照片最多用于 3 个词。加上专属图，共 216 个词有图片。
- 专属图全部离线，打开认词页和图卡不会触发网络；图库高清图仍只在用户点开后按需加载。
- 认词页使用“完整方形缩略图 + 联想说明”双栏卡，圆屏上不裁掉主要画面。
- 表圈焦点增加卡片渐变、轻微缩放和一次性柔光过渡；答题结果与完成页统一状态图形。无循环动画。

可直接覆盖安装，包名、签名、数据库和单词 ID 不变，旧进度、收藏、设置及当前学习组保留。版本号为 8。

验证：36 项 Android API 36 原生运行测试、63,830 条学习逻辑断言全部通过。新增验证覆盖 72 张专属图唯一性与解码、中文提示、专属图零网络请求、图库照片最大复用次数及圆屏布局。本版仍未连接真实 Watch7 实测。
