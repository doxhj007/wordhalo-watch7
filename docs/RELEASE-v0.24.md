# 词间 v0.24.0

这一版解决英美发音首响慢的问题，并重新收敛手表界面的视觉层级。

- UK / US 点击后优先使用启动时预热的 Wear OS 本机 TTS，省去 DNS、TLS 和远程缓冲等待。
- 自动选择英式或美式地区语音；手表缺少对应本机语音时才切换在线原声。
- 地区音标查询与发声分离，不再阻塞播放；不批量下载、不保存第三方录音。
- 退到后台会停止朗读、关闭 TTS、释放播放器并断开请求，不让手表持续保持 Wi-Fi。
- 卡片改为纯色 OLED 层级，去掉大面积渐变、柔光和夸张回弹。
- 虚拟表圈焦点改成单线平滑移动，保留清楚的选中状态和短过渡。
- 发音入口统一为 UK / US，发音页明确显示“本机发声”，小屏信息更简洁。
- README 已标注本项目由使用者在 Samsung Galaxy Watch7 44mm、One UI Watch 8 / Wear OS 6 上持续实机验证；自动化测试与用户实测范围分开说明。

可直接覆盖安装，包名、原签名、数据库和单词 ID 不变，学习进度、收藏、设置及当前学习组均保留。版本号为 9。

验证：36 项 Android API 36 原生运行测试、63,830 条学习逻辑断言全部通过。APK 使用与此前版本相同的签名证书，并通过 zipalign 与 APK Signature Scheme v3 校验。
