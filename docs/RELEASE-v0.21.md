# 词间 v0.21.0

当前版本基于 Wear OS 6，优先为三星 Samsung Galaxy Watch7 44mm 的 480 × 480 圆屏、虚拟表圈和触感交互开发与优化。后续计划逐步兼容不同品牌、尺寸和输入方式的 Wear OS 手表。

新增个人遗忘曲线与每日复习预测。应用根据每个词的复习阶段、答错状态和到期时间估算保持率，以 85% 为复习提醒线；每天开始一组时先抽到期词，一组装不下时优先选择预测最容易忘记的词。

学习概览扩展为四页，新增未来 7 天保持率曲线，以及现在、未来 24 小时和未来 3 天的复习数量。答错词仍在 10 分钟后复习，连续记得后间隔逐步扩展到 1、3、7、14、30、60 天。

已有用户直接覆盖安装即可，包名和签名不变，旧进度、当前组、收藏与设置会保留。通过 32 项 Android API 36 原生运行测试和 10025 条学习逻辑断言；本版尚未在真实 Watch7 上验证触感、表圈事件和蓝牙网络。
